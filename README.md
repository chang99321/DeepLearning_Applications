# DeepLearning_Applications

A collection of deep learning practice projects using publicly available datasets and benchmark problems. The projects explore image classification, transfer learning, and time-series forecasting using TensorFlow and Keras.

## Projects

### 1. Fashion MNIST
Build a multi-hidden-layer neural network using TensorFlow/Keras to classify Fashion MNIST images into 10 clothing categories.

### 2. CNNs on CIFAR-10
Improve CNN-based image classification performance on CIFAR-10 by experimenting with batch normalization, data augmentation, and dropout.

### 3. Transfer Learning with ImageNet
Apply feature extraction and fine-tuning with pretrained ImageNet models to classify the TensorFlow Flowers dataset. Compare MobileNetV2 with another pretrained model from Keras Applications.

### 4. Pneumonia Detection
Develop a three-class image classification model to distinguish Normal, Bacterial, and Viral pneumonia cases using transfer learning. Compare feature extraction and fine-tuning with different pretrained models.

### 5. Jena Climate Time Series Forecasting
Develop a data-windowing approach for multivariate, multi-step time-series forecasting using the Jena Climate dataset. Compare Dense, CNN, and RNN models using RMSE and R² scores.
